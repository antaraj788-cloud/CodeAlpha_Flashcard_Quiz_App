# StudyCards — Flashcard Quiz App (CodeAlpha Task 1)

## Features
- Question on the front and answer revealed with **Show answer**
- Next and Previous navigation
- Add, edit and delete flashcards
- Responsive layout for mobile and desktop
- Saves cards in browser `localStorage`

## Run
1. Extract `CodeAlpha_Task_1_Flashcard_Quiz_App.zip`.
2. Open the extracted folder.
3. Double-click `index.html` (or open it in Chrome/Edge/Firefox).
4. No installation, server, or internet connection is required.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `app.js` — flashcard functions and local storage

Data is stored in the browser on the device where the app is used. Clearing browser data may remove saved cards.
